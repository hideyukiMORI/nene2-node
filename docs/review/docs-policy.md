# Documentation Self-Review

Use for documentation-only PRs (README, `docs/`, ADRs).

**Policies:** `engineering-policy.md`, `../CONTRIBUTING.md`, `commit-conventions.md`

## Checklist

- [ ] User-facing prose is **English** (this repository policy).
- [ ] Links to sibling repos use stable GitHub URLs or relative `../NENE2` paths where local.
- [ ] Scope boundaries unchanged or `docs/scope.md` updated intentionally.
- [ ] ADR status/date updated when adding architectural decisions.
- [ ] No secrets, tokens, or real `.env` values in examples.
- [ ] `docs/todo/current.md` updated when direction or handoff changes.
- [ ] PR mentions this checklist for non-trivial doc changes.
