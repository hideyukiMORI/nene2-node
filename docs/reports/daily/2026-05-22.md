## Work themes

### Phase 2 application & data plane (FT67–80)

- Greenfield install, MySQL/PostgreSQL Compose, CI service jobs
- Business slice (orders), bearer on app routes, transactions, pagination
- Deploy checklist, Phase 2 friction index

### High-friction campaign (FT77–126)

- Idempotency, optimistic concurrency, FK/unique → Problem Details
- Webhook HMAC, read replica URL, Redis throttle/idempotency
- JWT throttle by `sub`, BOLA `assertResourceOwner`, timestamp semantics (docs)

### Quality & production readiness (afternoon focus)

- **Coverage:** lines/statements/branches **80%**; example UseCases **90%** per file
- **`createApp({ includeExamples })`:** production defaults examples off
- **`createJoseJwtVerifier`:** async JWKS (peer `jose`)
- **`registerProcessShutdown`:** SIGTERM/SIGINT pool cleanup
- **`commercial-readiness.md`**

### Example module hardening (v0.1.19–0.1.21)

- Bearer required on `/examples/notes` and `/examples/tags`
- Row ownership via JWT `sub` → **403** on cross-user access
- `createApp()` wires **422 / 409 / 403** domain handlers by default
- `created_at` persisted and returned as UTC ISO-8601 (`utcNowIso()`)
