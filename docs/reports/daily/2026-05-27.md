### FT177 — Pagination Boundary Attack (🔧 framework + 🔒 security)

`Number.parseInt` の silent coercion 問題（`"10.5"` → `10` など）を O(n) charCode ループ
（`isDigitString`）で根本解決。正規表現不使用で ReDoS 免疫。

| VULN | Input               | Before          | After            |
| ---- | ------------------- | --------------- | ---------------- |
| C    | `limit=10.5`, `1e2` | silently 10 / 1 | 422 invalid_type |
| D    | `limit=+10`, ` 10`  | silently 10     | 422 invalid_type |
| E    | 19-digit string     | overflow/NaN    | 422 invalid_type |
| F    | `limit=abc`, `0x10` | NaN/0           | 422 invalid_type |
| J    | `offset=999999`     | passthrough     | passthrough ✅   |
| L    | `"1"×50 + "x"`      | regex risk      | < 10 ms, 422     |

37テスト追加。`parseCursorQuery` にも同ガードを適用。
